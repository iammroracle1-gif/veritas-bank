# 🚀 Quick Start - Run Me First!

## ✨ Your app is configured to use SQLite (no database server needed!)

### Step 1: Run Setup (ONE TIME ONLY)
**Double-click:** `SIMPLE_SETUP.bat`

This will:
- Install all dependencies (takes 2-3 minutes)
- Create the database file
- Add demo data

### Step 2: Start the App (EVERY TIME)
**Double-click:** `start.bat`

This opens 2 windows:
- Backend Server (port 3000)
- Frontend Server (port 5173)

### Step 3: Open Browser
Go to: **http://localhost:5173**

### Step 4: Login
```
Admin: admin@veritasbank.com / Admin@123
User:  user@veritasbank.com / User@123
```

---

## That's it! 🎉

The app is now running with SQLite - no PostgreSQL or MySQL needed!

**Note:** Keep both terminal windows open while using the app.
